# Figure sources

Paper: [GUITAR: Structured Failure Diagnosis of GUI Agents via State Transitions](https://arxiv.org/abs/2609.34113).

The paper figures in this directory were taken from the [arXiv v2 source archive](https://arxiv.org/src/2609.34113v2). The PDFs are unchanged original assets. PNGs are 2,400-pixel-wide renderings of those PDFs, with their original colors, labels, and layout preserved.

| Figure | Original source asset | Repository assets |
| --- | --- | --- |
| Figure 1 — Overview | `figures/GUITAR.pdf` | [PNG](paper-overview.png) · [PDF](paper-overview.pdf) |
| Figure 7 — Automatic STG construction | `figures/build_graph_pipeline.pdf` | [PNG](paper-pipeline.png) · [PDF](paper-pipeline.pdf) |

`banner.png` is the README header, rendered from the editable `banner.svg` source for compatibility with local Markdown previews. It is a repository-specific decorative header; its small graph is a schematic illustration, not a figure or experimental result from the paper.
